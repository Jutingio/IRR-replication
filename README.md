# IRR论文核心结果复现说明

## 1. 项目简介

本项目复现 Kessler、Low 与 Sullivan（2019）关于 Incentivized Resume Rating（IRR）的研究结果。

本次复现范围限定为 Penn 样本，主要包括：

* Table 2：以招聘兴趣评分为因变量的 OLS、GPA尺度换算和 Ordered Probit 结果；
* Table 4：以招聘者判断的接受录用可能性评分为因变量的 OLS 和 Ordered Probit 结果；
* 扩展分析：将标准误聚类到招聘者层级，检验主要统计推断是否受到同一招聘者重复评分的影响。

本项目采用模块化代码结构。数据准备、Table 2、Table 4和扩展分析分别保存在不同的 do-file 中，并通过主文件 `00_run_all.do` 按顺序一次性运行。

## 2. 软件环境

* 软件：Stata
* 代码版本设定：Stata 15.1
*实际运行软件： Stata/MP 18.0 
* 操作系统：Windows 11，64位
* 外部扩展包：estout

使用更高版本的 Stata 时，建议在主 do-file 中保留 `version 15.1`，以尽量按照原复现环境解释相关命令。

## 3. 数据文件

本次复现使用作者公开提供的 Penn 原始数据：

* `IRRData_Penn.dta`：原始 Penn 实验数据；
* `IRRAnalysisFile_Penn_learning_wash.dta`：由 `01_prepare_data.do` 生成的分析数据。

原始数据不应被直接修改。所有人口统计变量、专业虚拟变量、领导经历变量及其他辅助变量均通过数据准备代码重新构造。

## 4. 代码文件

`code` 文件夹中的正式运行文件如下：

| 文件                        | 功能                                           |
| ------------------------- | -------------------------------------------- |
| `00_run_all.do`           | 主运行文件，依次调用其余四个模块                             |
| `01_prepare_data.do`      | 读取原始数据，构造变量，执行一致性检查并生成分析数据                   |
| `02_table2.do`            | 复现 Table 2第1—5列，包括OLS、GPA尺度换算和Ordered Probit |
| `03_table4.do`            | 复现 Table 4第1—4列，包括OLS和Ordered Probit         |
| `04_cluster_extension.do` | 对Table 2和Table 4的第3列实施招聘者层级聚类标准误扩展           |

`IRR_baseline_full_verified.do` 为完整基准核验脚本，用于保留模块化之前的整体核验版本，不属于标准的一次性运行流程。标准复现只需运行 `00_run_all.do`。

## 5. 运行方法

请保留原有文件夹结构，不要单独移动数据或 do-file。

在 Stata 中将工作目录设置为本项目的根目录：

```stata
cd "项目根目录的完整路径"
```

随后运行：

```stata
do "code/00_run_all.do"
```

主文件将依次执行：

```text
01_prepare_data.do
        ↓
02_table2.do
        ↓
03_table4.do
        ↓
04_cluster_extension.do
```

正常情况下不需要分别手动运行四个子文件。

如果只需要重新运行某个回归模块，应先确保 `01_prepare_data.do` 已经成功运行，并且分析数据文件 `IRRAnalysisFile_Penn_learning_wash.dta` 已经生成。

## 6. 日志文件

一次完整运行将生成以下分阶段日志：

| 日志文件              | 对应内容            |
| ----------------- | --------------- |
| `IRR_stage1.log`  | 数据准备、变量构造及一致性检查 |
| `IRR_stage02.log` | Table 2复现结果     |
| `IRR_stage03.log` | Table 4复现结果     |
| `IRR_stage04.log` | 招聘者层级聚类标准误扩展结果  |

日志记录了各阶段执行的命令、回归输出和检查结果，可用于核对代码是否完整运行及追踪错误。

如果代码中的日志命令使用 `replace`，再次运行主文件将覆盖同名的旧日志，而不是在原日志末尾继续追加。

## 7. 结果核验标准

代码成功运行后，应至少得到以下关键结果：

* Penn 样本共有2,880条观测；
* 数据包含72位招聘者，每位招聘者评价40份简历；
* Table 2第3列的观测数为2,880，(R^2=0.483)；
* Table 4第3列的观测数为2,880，(R^2=0.492)；
* GPA、顶级实习和第二段普通实习在两张表的主规格中均显著为正；
* 聚类标准误扩展包含72个招聘者聚类；
* 采用招聘者聚类标准误后，核心变量的方向和统计显著性结论保持不变。

论文原表未使用显著性星号。因此，复现判断主要依据样本量、模型设定、系数、标准误、拟合度和联合检验结果，而不要求自行导出表格的星号格式与原文一致。

## 8. 复现范围说明

本项目属于核心结果复现，而不是对论文全部数据、全部表格和全部异质性分析的完整复现。

成功复现表示：在相同公开数据、变量构造和模型设定下，代码能够在论文报告精度内重新生成 Table 2和Table 4的主要估计结果。

这不等于重新验证原始数据收集过程，也不表示研究结论已经对所有模型形式、样本选择或外部招聘环境得到全面验证。
